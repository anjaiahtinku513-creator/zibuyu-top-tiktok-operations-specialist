# Zibuyu Top TikTok Operations Specialist

This repository publishes the Codex personal plugin source for the Zibuyu TikTok apparel operations workflow.

It includes:

- `.codex-plugin/plugin.json` for plugin metadata.
- `skills/` for the bundled workflow skills.
- `hooks/` for local-file PopBoom upload support.
- `tests/` for prompt-contract and hook validation.
- `plugin-packages/zibuyu-top-tiktok-operations-specialist.zip` as the installable package.

## Install

Download the latest ZIP package:

https://github.com/anjaiahtinku513-creator/zibuyu-top-tiktok-operations-specialist/raw/main/plugin-packages/zibuyu-top-tiktok-operations-specialist.zip

Unzip it and install the contained `zibuyu-top-tiktok-operations-specialist` plugin folder through your Codex plugin install flow or into the Codex plugin directory used by your environment.

## Scope

The package contains plugin instructions, validators, tests, and static assets only. It does not include private browser sessions, tokens, user product files, generated videos, FastMoss exports, PopBoom ledgers, or other run-specific business data.

Source version: `0.1.0+codex.20260823142222`.
